Utang Tracking System
The Utang Tracking System is a web-based application designed to help manage customer debts and payments in one place. It provides a simple way to organize customer records, track outstanding balances, and monitor repayment activity.

The system is built with React, Express.js, and PostgreSQL, with the goal of making debt tracking more organized, accessible, and easier to maintain.

Technologies Used
React
Node.js and Express.js
PostgreSQL
Project Purpose
This project explores how a full-stack web application can be used to manage debt records and payments, while applying concepts such as frontend-backend communication, database management, authentication, and user roles.

Educational Project
This system was created for educational purposes as part of a learning project. It is intended to demonstrate and practice web development and database concepts, and is not necessarily intended for production or commercial use.
